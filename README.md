# Carnation Tracker

แปลงข้อความจาก LINE → Excel พร้อมตกแต่งมืออาชีพ
วางข้อความ → กดแปลง → ดาวน์โหลดไฟล์ .xlsx

## ใช้งาน
เปิด https://rathasartl.github.io/carnation-tracker/

## ฟีเจอร์
- Parser รองรับทั้ง "รายการของแจก" และ "สรุปยอดขาย"
- ปี 69 → 2569 (auto)
- 4 ชีต: ข้อมูล, สรุปยอดแจก, สรุปยอดขาย, สต็อกล่าสุด
- 100% client-side — ข้อมูลไม่ออกจากเบราว์เซอร์

## Stack
- ExcelJS 4.4 (CDN)
- HTML/CSS/JS ล้วน ไม่มี backend
